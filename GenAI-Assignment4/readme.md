# Assignment 4 - File Handling in Python

## About This Assignment

This is my fourth Python assignment. In this assignment, I practised file handling in Python.

I learned how to create files, write data, read data, and add new data to existing files.

I used basic Python concepts and did not use any external libraries.

## Tasks Completed

### Task 1: Write Sales Records

I created a list of sales amounts and saved each sale on a new line in `sales_data.txt`. After writing the data, I opened the file and printed its contents.

### Task 2: Read File in Different Ways

I used `read()`, `readline()`, and `readlines()` to read the sales file in different ways. I also converted the sales values into integers.

### Task 3: Append New Sales

I added new sales amounts to the existing file using append mode. I also printed the updated file and counted the total lines.

### Task 4: Generate Summary Report

I read the sales data from the file and calculated total sales, highest sale, lowest sale, and average sale.

### Task 5: Create Product Info File

I took input for three products and their prices. I saved the information in `products.txt` and printed the file contents.

### Task 6: Read File Safely

I asked the user to enter a filename. I checked whether the file exists using `os.path.exists()` and displayed a message if the file was not found.

### Task 7: Export Discounted Prices

I created a dictionary of product prices and applied a discount entered by the user. I saved the original and discounted prices in `discount_report.txt`. I also calculated the total number of items and average discounted price.

## Concepts Used

- `open()` and `with open()`
- File modes: `r`, `w`, `a`, `r+`, and `w+`
- `read()`, `readline()`, and `readlines()`
- Writing and appending files
- Lists and dictionaries
- Loops and conditions
- Basic calculations
- `os.path.exists()`

## Files Created

- `products.txt`
- `discount_report.txt`
